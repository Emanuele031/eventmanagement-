# eventmanagement

Applicazione backend per la gestione di eventi, sviluppata in Java con Spring Boot ed esposizione di API REST.

## Descrizione

Sistema gestionale che permette di creare, consultare, modificare ed eliminare eventi. L'applicazione espone API REST che consentono a un client esterno di interagire con i dati, appoggiandosi a un database PostgreSQL per la persistenza.

## Funzionalità

- Creazione e gestione di eventi
- Operazioni CRUD complete (creazione, lettura, aggiornamento, eliminazione)
- API REST per l'accesso ai dati
- Persistenza su database PostgreSQL

## Tecnologie utilizzate

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- API REST

## API

L'applicazione espone endpoint REST per la gestione degli eventi. Le principali operazioni disponibili includono il recupero della lista eventi, il dettaglio di un singolo evento, la creazione, la modifica e l'eliminazione.
